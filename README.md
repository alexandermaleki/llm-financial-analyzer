# LLM Financial Analyzer

A personal project to learn how to build with LLMs, starting from a single API call and working up toward RAG and agentic workflows over financial documents.

## Motivation

I wanted real experience going beyond a single API call, including structured outputs, chaining steps together, and comparing results against a simple baseline. This is a learning project, not a polished tool, and it will evolve as I go.
